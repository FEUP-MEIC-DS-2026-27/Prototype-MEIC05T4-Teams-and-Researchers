# HumanISE.info - Researchers & Teams

A reactive information radiator for HumanISE researchers, teams, collaborations,
and research areas.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Run the tests with `npm test` and create a production build with `npm run build`.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
